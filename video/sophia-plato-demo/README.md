# Sophia · диалог с Платоном

[Готовый ролик](./sophia-plato-demo.mp4) для презентации. MP4 с H.264, 1920 × 1080, 60 кадров/с и длительностью ровно 30 секунд. Звуковой дорожки нет.

## Монтаж

| Время | Сцена |
| --- | --- |
| 00:00–00:03 | Логотип и «Философия становится диалогом». |
| 00:03–00:07 | Главная Sophia, приближение к карточке разговора и открытие чата. |
| 00:07–00:12 | Набор и отправка вопроса о справедливости, затем ожидание. |
| 00:12–00:19 | Ответ Платона, акцент на «каждому отводится своё» и прокрутка до конца реплики. |
| 00:19–00:26 | Тезис пользователя о возврате взятого. Платон проверяет правило встречным вопросом. |
| 00:26–00:30 | Затемнение и «Не просто изучай философию. Философствуй». |

Обе реплики Платона получены через настоящий сервер Sophia в одном диалоге и сверены с текстом в браузере. Полная переписка лежит в [transcript.json](./transcript.json). Время ожидания сжато при монтаже. Текущий чат не показывает отдельные ссылки на материалы корпуса. Сборка ролика использует кадры существующих компонентов Sophia и её шрифты Manrope.

## Повторный экспорт

Установите Node.js 24 и FFmpeg с кодировщиком `libx264` и утилитой `ffprobe`. Из каталога видеопроекта выполните:

```powershell
npm.cmd ci
npm.cmd run render
npm.cmd run verify
```

Если утилиты находятся вне `PATH`, укажите пути в переменных `SOPHIA_DEMO_FFMPEG` и `SOPHIA_DEMO_FFPROBE`. Для проверки композиции без экспорта используйте `npm.cmd run render -- --stills ./preview`.

Камера, прокрутка, курсор, расстановка акцентов и тайминг находятся в [timeline.mjs](./timeline.mjs). Снимки и координаты элементов, включая тексты титров, находятся в [captures](./captures). Для экспорта достаточно этих ресурсов и локальных шрифтов. Он не запускает Sophia и не обращается к модели.

## Повторный захват интерфейса

После установки зависимостей основного приложения и Chromium для Playwright соберите Sophia командой `npm.cmd run build` из корня репозитория. Затем из каталога видеопроекта запустите `npm.cmd run record -- --replay`. Команда воспроизводит сохранённый диалог в настоящем интерфейсе и повторяет захват без запросов к модели. Запуск `npm.cmd run record` без аргументов записывает новый диалог с двумя платными запросами к чату и использует серверные настройки Sophia.

Для захвата запускается локальный сервер `127.0.0.1` с отдельной временной базой, тестовой почтой и правом `ai_chat` у демонстрационной учётной записи. После захвата сервер останавливается, временные данные удаляются. Код приложения и настройки развёртывания находятся за пределами видеопроекта.
