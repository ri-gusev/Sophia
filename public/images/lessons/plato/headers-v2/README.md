# Purpose-composed Plato header panoramas

Created for Sophia with built-in image_gen on 2026-11-15 in response to the request to redraw header images so their principal subjects fit. These are nine new panoramic compositions rather than crops of the previous 3:2 paintings. No third-party artwork, stock photograph or film frame was supplied.

All nine native outputs are **2172 × 724 (3:1)**. Exported as local WebP using existing Sharp, quality 88 / effort 6; total **3,274,580 bytes**. `generation.json` contains every final prompt, original PNG filename, dimensions, byte count and generation-session ID. Originals are preserved in generated_images; the earlier lesson images remain in their previous folder.

Desktop displays the entire panorama with `object-fit: contain` in a 312 × 104 px image area. Mobile uses a centered 136 × 88 px window around the central principal subjects. All nine actual desktop/mobile renders were visually inspected together, in addition to image-loading/aspect-ratio tests. Next Image and matching prefetch srcset serve appropriately sized variants; mobile sizes account for the cover image's required height and density.

These remain artistic interpretations, not documentary evidence or authenticated likenesses. All figures and episodes are illustrative; prison pupils are anonymous, without asserting Plato was present. Project-generated assets have no attached third-party stock attribution; this provenance statement does not promise copyright exclusivity. Generation prompts and origin must not be confused with historical sources for lesson text.
