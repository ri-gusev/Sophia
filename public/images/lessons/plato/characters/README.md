# Full-length philosopher figures

Three separate transparent game assets created with built-in image_gen on 2026-11-16 for the sixth-scene ordering exercise. These are artistic interpretations of Aristotle, Socrates and Plato. Each figure includes the complete head, hands, robe and sandalled feet, in a shared softly painted realistic style with ivory, sage and olive clothing.

Files are `aristotle.webp`, `socrates.webp`, and `plato.webp`. Each image is 667 × 1000 px with an alpha channel. Export uses Sharp, height 1000 px, WebP quality 90 and effort 6, preserving transparency. Original PNG files remain in the generated-images directory. Exact prompts and source paths are recorded in `generation.json`.
