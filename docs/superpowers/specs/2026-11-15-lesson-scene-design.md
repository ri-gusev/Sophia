# Бесшовная сцена урока

Основание: подробное задание пользователя от 2026-11-15. Обновляется существующее вступление под картой, маршрут и содержание сохраняются.

Единственный подход, соответствующий ограничениям: общий `LessonScene` с декоративным локальным изображением и CSS mask-image. Самостоятельная страница или две панели противоречат заданию. Фон сцены совпадает с существующим фоном страницы через `--page-background`; текст и задания не получают подложку. Desktop: изображение слева растворяется до области чтения справа; mobile: изображение сверху растворяется до начала текста.

Шаблон принимает ID сцены, изображение, контекст, этап, заголовок, абзацы, заключительный вопрос, children для задания, navigation и необязательную позицию сцены. Смена ID перезапускает появление; 1.2 секунды opacity/translateY(10px), задержки по 40 ms. Reduced motion полностью отключает анимацию.

Существующее вступление остаётся одной сценой с прежним вопросом и тремя radio-вариантами. «Сцена 1 из 1» показывает позицию, не завершение или сохранённый прогресс. Продолжение не создаётся: дальнейших сцен в данных нет. Шаблон готов принимать настоящие кнопки навигации от следующего урока.

Иллюстрация создаётся image_gen, оптимизируется в локальный WebP; происхождение и промпт фиксируются рядом с ресурсом. Новых зависимостей, философского содержания, API или хранилища нет.

Проверка: загрузка изображения, прежние ответы/фокус/навигация, axe, анимации, отсутствие переполнения и визуальный просмотр 320/390/768/1440 px; типы, lint, build и полный Playwright с отдельным отчётом о чужих сбоях.
