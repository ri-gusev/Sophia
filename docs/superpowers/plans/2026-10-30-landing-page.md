# Sophia Landing Page Implementation Plan

**Goal:** реализовать Phase 1 из задания пользователя от 2026-10-30 в локальном Next.js-приложении.

**Architecture:** серверная страница собирает секции; клиентскими остаются меню, упражнение и обёртка Motion. Учебные данные находятся в `src/content/landing.ts`. Общая кнопка следует композиции shadcn/ui, стили и палитра централизованы.

**Tech Stack:** Next.js App Router, React, TypeScript strict, Tailwind CSS, shadcn/ui, Lucide, Motion. npm и Node.js >=20.9.0.

**Spec:** задание «Sophia — Phase 1: Landing Page Implementation»; границы — [MVP](../../product/MVP.md), визуальные требования — [DESIGN_SYSTEM](../../design/DESIGN_SYSTEM.md).

## Ограничения

Только локальная реализация; без коммита и публикации. Без авторизации, БД, платежей, личного кабинета, движка уроков, ИИ и картографического движка. Все CTA ведут к демо. Вход явно недоступен. Прогресс, маршрут и атлас обозначены как примеры. Шрифт Manrope с кириллицей поставляется локально.
