# Atlas desktop quality implementation plan

**Goal:** Реалистичная спутниковая Земля, детальнее на desktop; существующие UI и архитектура сохраняются.
**Source:** задание пользователя «Sophia Atlas — улучшение визуального качества 3D-глобуса», 2026-11-08.

- [x] Зафиксировать прежний стилизованный вид и оригинальную NASA-текстуру при одинаковом свете/камере в `artifacts/atlas-quality/`.
- [x] Проверить официальный NASA-источник высокого разрешения и условия использования; получить 8192 × 4096 уменьшением более крупного оригинала, сохранить резерв 4096 × 2048 и происхождение.
- [x] Убрать преобразование цветов и sharpening. Сохранить штатный материал, sRGB, trilinear mipmaps, горизонтальное повторение на шве, ограниченную анизотропию. Выбирать 8K по возможностям GPU/устройства, иначе 4K; обрабатывать ошибку 8K резервной загрузкой.
- [x] Настроить направленный/слабый заполняющий свет без пересвета. Краевое свечение не добавлено: выбран чистый контур на светлом фоне без дополнительной геометрии/шейдера. Demand-render, без новых библиотек/постэффектов.
- [x] Добавить регрессию resize с изменённым направлением камеры: сохранять направление, увеличивать только необходимую дистанцию; явный сброс возвращает исходный вид.
- [x] Проверить fallback, качество/шов/приближение, ошибки WebGL, управление, отсутствие непрерывного рендера и остальные страницы. Typecheck/lint/build/Playwright.
- [x] Обновить текущий статус и профильные документы по фактам; перечислить изменения и ограничения.

Итог: настоящий 21600px NASA-оригинал → 8K/4K, штатный материал; сохранены модульные границы. Ревью выявило imperative DPR, перезаписываемый пропом Canvas: HiDPI-тест сначала RED (1.5 вместо 2), затем GREEN после декларативной настройки. Полный набор — 84 passed, 4 skipped; детали и ограничения в CURRENT_STATE.

Границы: без чата/RAG/обучения/маркеров/новых зависимостей. Не имитировать городскую детализацию. Мобильный UI не перерабатывается. Работа в текущем checkout без коммитов/публикации.
