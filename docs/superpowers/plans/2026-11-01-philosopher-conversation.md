# Интерфейс разговора с философом

Основание: пользователь попросил кнопку на `/learn` и в средней карточке главной, окно разговора, выбор Платона/Аристотеля/Марка Аврелия с фотографиями скульптур и место для будущего API-ключа. Поведение модели сейчас исключено.

Решение реализации: один общий клиентский компонент с нативным модальным dialog. На desktop слева список собеседников, справа область разговора; на mobile список прокручивается горизонтально над областью разговора. Все три профиля можно выбрать, черновик доступен только для Платона; отправка отключена и причина видима. Новый маршрут и зависимости не нужны. Альтернатива с отдельной страницей потребовала бы ухода с карты, а отдельные реализации окон на двух страницах дублировали бы поведение.
