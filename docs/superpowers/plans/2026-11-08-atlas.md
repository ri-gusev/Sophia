# Sophia Atlas Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Интерактивная Земля на `/atlas` в едином UI Sophia.
**Architecture:** Серверная страница, клиентская оболочка с динамической сценой без SSR, отдельные OrbitControls и локальные CSS. Общие кнопки и токены сохраняются.
**Tech Stack:** Next.js App Router, TypeScript strict, Three.js, Fiber 9 (React 19), Drei, Playwright.
**Spec:** `docs/superpowers/specs/2026-11-08-atlas-design.md`, согласовано пользователем «продолжа».

## Global Constraints

- Не менять `/learn`, чат, RAG и данные пользователя.
- Активировать существующий пункт шапки без дублирования.
- Только локальная текстура с проверенным источником и условиями использования.
- UI Sophia; тёмная только сцена. Без маркеров, подписей, облаков и постэффектов.
- Работа в текущей папке; без коммитов и публикации.

## Review Focus

- Узкий и горизонтальный экран: Земля целиком при первом показе, UI доступен.
- Отказ текстуры: понятная ошибка и повторная попытка.
- Отсутствие/потеря WebGL: понятное сообщение вместо пустого canvas.
- Повторный вход и выход: освобождение ресурсов, отсутствие runtime-ошибок.
- Мобильные жесты: вращение и pinch без прокрутки страницы.
