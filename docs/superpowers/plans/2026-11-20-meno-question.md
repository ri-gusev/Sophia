# Первый слайд блока о добродетели

Основание: подробный сценарий пользователя «Sophia — Блок 2, урок 1, слайд 1». Реализация в текущем рабочем каталоге, без коммита и публикации.

## Решение и границы

Расширить существующий union сцен типом `virtue-intro`, отделить контент в `virtue-intro-data.ts`, представление и локальную навигацию в `VirtueIntroScene`. Общий движок и первый блок сохраняются. Универсальная новая система и использование оцениваемого single-choice не подходят: здесь нет правильного ответа. Данные урока содержат только `meno-question`; статус блока `partial`. Общий индикатор не должен показывать завершённый урок из-за наличия лишь одного слайда.

## Последовательность

1. Тест регистрации: `readLessonLocation` распознаёт урок, список сцен равен `["meno-question"]`, нет финала завершения. Запустить до регистрации и проверить ожидаемый отказ.
2. Добавить данные, сцену, стили, каталог и ветку представления. Пять этапов управляются пользователем. Выбор хранится в React при возврате, повтор очищает его. Выход использует существующий `onClose`; запись прогресса отсутствует.
3. Создать единую иллюстрацию с референсом Сократа, сохранить WebP и промпт в `public/images/lessons/virtue/`. Плавное появление, последовательные карточки, отступление выбора, вопрос и реплика; reduced motion отключает анимации и задержки.
4. Выполнить typecheck, lint, build, профильные Playwright и регрессии. Проверить четыре ширины, пять состояний, выбор/возврат/повтор/каталог, axe и отсутствие записи завершения. Просмотреть снимки.
5. Обновить CURRENT_STATE, TESTING и журнал решения с фактическими результатами.

## Риски для проверки

Каталог на mobile должен открываться после выхода; прежние тесты могут ожидать пустой второй блок. Скрытые карточки поворота не должны попадать в фокус. Переходы не должны пропускать этапы из-за таймеров. Ширины 390/768/1024/1440 не должны давать переполнение. Частичный урок не должен показывать 100% прогресса.
