# Аудит возможных трансграничных передач данных Sophia

25 ноября 2026 года проверены почтовые домены, код приложения и инструкции по запуску. Для вывода о фактических передачах нужны настройки развёртывания, сведения об обработчиках и условиях обслуживания.

## Почтовые домены

Для каждого домена сверены MX-записи публичного DNS (`Resolve-DnsName -Type MX -DnsOnly`) и доступные сведения оператора. Строки с несколькими доменами объединяют одинаковый результат проверки MX.

| Сервис | Проверенные домены | MX | Подтверждение |
| --- | --- | --- | --- |
| Яндекс Почта | `yandex.ru`, `ya.ru` | `mx.yandex.ru` | [Условия Яндекс Почты, п. 2.2](https://yandex.ru/legal/mail_termsofuse/ru) |
| Почта Mail | `mail.ru`, `inbox.ru`, `list.ru`, `bk.ru`, `internet.ru` | `mxs.mail.ru` | [Домены основных ящиков Mail](https://help.mail.ru/mail/account/beautiful/) |
| Рамблер/почта | `rambler.ru`, `ro.ru`, `lenta.ru`, `autorambler.ru`, `myrambler.ru` | `inmx.rambler.ru` | Все пять доменов направляют входящие письма на MX в домене `rambler.ru`. [Почтовый сервис Рамблера](https://mail.rambler.ru/) |
| VK Почта | `vk.com` | `mxs.mail.ru` | [Справка VK Почты об адресах `@vk.com`](https://help.mail.ru/vkmail/account/name/) |
| VK | `vk.ru` | `mxs.mail.ru` | Подтверждён как корпоративный почтовый домен VK. [Контакты VK](https://vk.company.ru/ru/press/contacts/) · [Почта VK WorkSpace](https://biz.mail.ru/docs/on-premises/admin-panel/mail-administration/mail-administration.pdf) |

MX-запись показывает сервер входящей почты. География дальнейшей обработки, переадресации и хранения требует отдельной проверки.

## Потоки для проверки на развёрнутом экземпляре

| Поток | Что установлено в репозитории | Какие сведения нужны |
| --- | --- | --- |
| Письма аккаунтов | В публичном режиме приложение отправляет адрес получателя и ссылку подтверждения или сброса через Yandex Cloud Postbox по SMTP. Восстановление продолжает отправлять письма на действующие адреса, включая зарубежные сервисы. Историческая проверка доставки в Gmail указана в [состоянии проекта](../development/CURRENT_STATE.md). [Настройки транспорта](../development/ACCOUNT_SERVER.md#smtp-postbox) | Договор и условия хранения писем и журналов, регион обработки Postbox, обработчики доставки и политика пересылки. Отдельно оценить отправку на зарубежные адреса при восстановлении. |
| Аккаунты, прогресс и инфраструктура | SQLite хранит адрес, имя, данные авторизации и прогресс на сервере. В репозитории описаны HTTPS-прокси и резервное копирование. [Схема данных](../architecture/ACCOUNTS_AND_PROGRESS.md) · [Эксплуатация](../development/ACCOUNT_SERVER.md) | Установить оператора и страну размещения VPS и резервных копий. Сверить географию доступа администраторов, состав и сроки хранения логов, наличие CDN, WAF, мониторинга и внешних сборщиков логов. |
| Поддержка | Футер направляет обращения, включая вопросы о персональных данных, на `support.sophia@ro.ru`. [Контакт](../../README.md#контакты) | Проверить делегированный доступ, почтовые клиенты, пересылку, хранение вложений и интеграции с внешними сервисами поддержки. |
| OpenAI | Публичный чат закрыт. В разрешённом локальном режиме Responses API получает сообщения, историю и контекст, а Embeddings API получает тексты для поиска или индексации. Пользователь может указать персональные данные в свободном тексте. Запрос Responses содержит `store: false`. | Браузер | Шрифты поставляются пакетом в приложении. В прикладном коде не обнаружены подключённые SDK аналитики. В уроках и Атласе есть внешние ссылки на источники. | Проверить сетевые запросы на публичном экземпляре, включая ресурсы, которые могут добавлять прокси, хостинг или подключённые расширения платформы. |

После проверки развёртывания для каждого фактического потока нужно задокументировать получателя, страну, категории данных, цель, основание, договор, сроки хранения и удаление. Для подтверждённой трансграничной передачи следует отдельно проверить применимость требований статьи 12 и уведомления Роскомнадзора. [Статья 12 Федерального закона № 152-ФЗ](https://base.garant.ru/12148567/b6e02e45ca70d110df0019b9fe339c70/).
