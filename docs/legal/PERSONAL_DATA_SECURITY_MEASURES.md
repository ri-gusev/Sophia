# Меры защиты персональных данных, реализованные в Sophia

Перечень предназначен для подготовки уведомления Гусева Романа Игоревича об обработке персональных данных в Sophia. Укажите в уведомлении фактические сведения о месте базы по документам поставщика. [Портал Роскомнадзора](https://pd.rkn.gov.ru/)

## Инфраструктура по подтверждению оператора

| Область | Действующие меры |
| --- | --- |
| Размещение | VPS Yandex Compute Cloud в РФ, Ubuntu 24.04, Next.js, Nginx, systemd. SQLite хранится в `/var/lib/sophia/accounts.sqlite`. Приложение работает от отдельного непривилегированного пользователя `sophia-app` и слушает локальный интерфейс. |
| Сеть и администрирование | HTTPS с сертификатом Let's Encrypt, TLS 1.2/1.3 и HSTS. Автоматическое продление проверено. UFW запрещает входящие подключения по умолчанию, разрешены TCP 22, 80 и 443. SSH принимает только ключи. Прямой вход под root запрещён. |
| Почта | Служебная почта отправляется через Yandex Cloud Postbox. Оператор проверил STARTTLS, аутентификацию и доставку. Входящие обращения принимаются в Рамблер Почте, доступ к ящику поддержки подтверждён. |
| Бэкапы | Ежедневное копирование SQLite через Online Backup API. GPG AES-256, локальная ротация через 14 суток и отдельное ограниченное хранение ключа. Предусмотрен ручной перенос зашифрованной копии. Оператор проверил расшифровку и целостность снимка. |

## Меры в приложении

| Область | Фактически реализовано в приложении |
| --- | --- |
| Аутентификация | Проверка владения email одноразовой ссылкой перед созданием аккаунта. В базе хранятся хеши паролей Argon2id с индивидуальной случайной солью, памятью 64 МиБ и тремя проходами. При проверке неизвестного адреса также вычисляется Argon2id. Число одновременных операций хеширования ограничено. |
| Сессии и восстановление | Случайные 256-битные токены с SHA-256 на сервере, проверка назначения и срока, одноразовое погашение токенов письма. Сессия отзывается при выходе, все сессии аккаунта отзываются при сбросе пароля и удалении. В HTTPS-режиме поддерживается host-only cookie с `Secure`, `HttpOnly`, `SameSite=Lax` и `Path=/`. |
| Разграничение доступа | Сессия привязана к подтверждённому аккаунту. Изменения профиля и прогресса проверяют актуальность сессии и совпадение ожидаемого ID. Управление рассылкой зависит от сессии, удаление и отзыв обязательного согласия также требуют актуального пароля. Проверка доверенного заголовка прокси применяется в API аккаунтов и прогресса. |
| Защита запросов | Для изменяющих запросов проверяется точный Origin, формат, объём и допустимый состав данных. Действуют квоты входа, восстановления, регистрации, progress API и повторных согласий. Вход сочетает сетевую, общую и парную квоты. Запросы писем имеют одинаковое подтверждение для известного и неизвестного адреса при одинаковых квотах и конфигурации. |
| Хранение и целостность | Серверные записи аккаунтов находятся в отдельной SQLite, применяются транзакции и внешние ключи. Тексты обязательных редакций и сведения о времени подтверждения привязаны к заявке и аккаунту. История рассылки содержит даты переходов и ссылку на неизменяемый снимок редакции. Сетевой идентификатор для квот вычисляется с секретом прокси. |
| Минимизация | Промежуточные ответы и коллекции читалки хранятся в браузере. Разделы гостя и аккаунта разделены, выбор личной цитаты и закладки обрабатывается клиентом без передачи идентификатора в HTTP URL. В профиль переносится только поддерживаемый учебный прогресс. Прикладные сообщения о сбоях и ограничителях исключают адреса, ссылки и тела. |
| Защита браузера и почты | Приложение задаёт политику запрета встраивания, ограничения объектов, base и отправки форм, запрет передачи Referer и ограничение доступа к камере, микрофону и геолокации. Ответы API аккаунтов и прогресса имеют `no-store`. Для SMTP код требует STARTTLS и проверяет сертификат. |
| Удаление и сроки | Удаление аккаунта транзакционно удаляет связанные серверные записи и отзывает токены. Прикладная очистка удаляет просроченные сессии, заявки, токены и счётчики, затем запрашивает очистку WAL. SQLite открывается с `secure_delete`. Профиль очищает раздел текущего аккаунта в локальном хранилище текущего браузера. |

Карантинное восстановление со сверкой удалений, полным отзывом восстановленных сессий и отключением прежних паролей проверено на синтетической SQLite. Полный сценарий на VPS остаётся условием допуска. Место внешних копий, фактические сроки журналов и обращений, дополнительные меры для конкретной ИСПДн, шифрование дисков и сертификация СЗИ требуют подтверждения для включения в уведомление.
