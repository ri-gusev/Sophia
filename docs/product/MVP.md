# MVP: первый этап

Область первого этапа — Landing Page с демонстрацией подхода к обучению. Это согласованные требования, а не перечень выполненных функций. Статус реализации — в [CURRENT_STATE.md](../development/CURRENT_STATE.md).

| Входит | Критерий готовности |
| --- | --- |
| Главная страница | Объясняет назначение Sophia и предлагает понятное основное действие |
| Демонстрационный философский вопрос | Пользователь выбирает ответ и получает содержательную обратную связь; демонстрационный статус обозначен |
| Превью образовательного маршрута | Показывает пример последовательности обучения без обещания доступного полного курса |
| Превью исторического атласа | Передаёт идею исторического контекста и связей без имитации готового атласа |
| Адаптивный интерфейс | Основные сценарии работают на мобильных и настольных экранах с клавиатуры |

Не входят: полноценная авторизация, платежи, база данных и ИИ-собеседник. Долговременное сохранение прогресса не предполагается. Для демонстрации достаточно отдельных типизированных файлов данных.

Этап принимается после функциональной проверки перечисленных сценариев, проверок по [TESTING.md](../development/TESTING.md) и обновления фактического состояния. Создание документации само по себе не завершает MVP.
