# MVP: главная и карта курса

Актуальная область — упрощённый Landing Page из Phase 2 и согласованная пользователем интерактивная карта курса на `/learn`. Карта развивает каркас Phase 2, сохраняя границы без учебного движка и хранения. Это согласованные требования, а не перечень выполненных функций. Статус реализации — в [CURRENT_STATE.md](../development/CURRENT_STATE.md).

| Входит | Критерий готовности |
| --- | --- |
| Главная страница `/` | Ровно три основные секции: Hero, превью курса, выбор направления; необходимая навигация |
| Демонстрационный вопрос в Hero | Три равноправных ответа на вопрос о корабле Тесея, общее объяснение без оценки правильности и повтор; состояние только локальное |
| Превью образовательного маршрута | Показывает пример последовательности обучения без обещания доступного полного курса |
| Выбор направления | Одна карточка основного курса и две карточки «— / Скоро» без активных кнопок |
| Страница `/learn` | Название курса, возврат на `/` и горизонтальная карта из пяти эпох по пять круглых шагов; логотип и компактная ссылка «Как это работает» сохранены |
| Пейзаж карты | Масштаб выбранного прототипа: мир 5900 × 650 px, детальные рисованные области шириной 1180 px, одна эпоха на видимую область карты и естественные переходы; встроенная тропа и объёмные кнопки под материалы эпох; без видимых прямоугольных стыков и крупных заголовков внутри пейзажа |
| Навигация карты | Компактный выбор эпох, перетаскивание, прокрутка, сенсорные жесты и клавиатура; reduced motion и отсутствие горизонтального переполнения страницы |
| Ознакомление с темой | Нажатие шага открывает доступный диалог с темой и явным сообщением о том, что полный урок пока недоступен; закрытие возвращает фокус |
| Адаптивный интерфейс | Основные сценарии работают на мобильных и настольных экранах с клавиатуры |

Все CTA курса ведут на `/learn` через `next/link`; логотип ведёт на `/`, ссылка «Как это работает» — на `/#how-it-works` с обеих страниц. Атлас и вход неактивны с пометкой «Скоро».

Не входят: авторизация, платежи, база данных, ИИ-собеседник, полноценный учебный движок, XP и сохранение прогресса. Ознакомительные шаги карты не означают завершённые или разблокированные уроки. Старое отдельное упражнение, атлас-превью, лента вопросов, финальный CTA и footer Phase 1 больше не входят в текущую главную. Для демонстрации достаточно типизированных файлов данных и локального состояния интерфейса.

Этап принимается после функциональной проверки перечисленных сценариев, проверок по [TESTING.md](../development/TESTING.md) и обновления фактического состояния. Создание документации само по себе не завершает MVP.
