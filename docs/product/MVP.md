# MVP: актуальные границы Phase 2

Актуальная область по заданию Phase 2 от 2026-10-30 — упрощённый Landing Page и минимальный каркас `/learn`. Это согласованные требования, а не перечень выполненных функций. Статус реализации — в [CURRENT_STATE.md](../development/CURRENT_STATE.md).

| Входит | Критерий готовности |
| --- | --- |
| Главная страница `/` | Ровно три основные секции: Hero, превью курса, выбор направления; необходимая навигация |
| Демонстрационный вопрос в Hero | Три равноправных ответа на вопрос о корабле Тесея, общее объяснение без оценки правильности и повтор; состояние только локальное |
| Превью образовательного маршрута | Показывает пример последовательности обучения без обещания доступного полного курса |
| Выбор направления | Одна карточка основного курса и две карточки «— / Скоро» без активных кнопок |
| Страница `/learn` | Логотип, название курса, статус разработки и возврат на `/`; компактная ссылка «Как это работает» возвращает к третьей секции |
| Адаптивный интерфейс | Основные сценарии работают на мобильных и настольных экранах с клавиатуры |

Все CTA курса ведут на `/learn` через `next/link`; логотип ведёт на `/`, ссылка «Как это работает» — на `/#how-it-works` с обеих страниц. Атлас и вход неактивны с пометкой «Скоро».

Не входят: авторизация, платежи, база данных, ИИ-собеседник, полноценный учебный движок, XP и сохранение прогресса. Старое отдельное упражнение, атлас-превью, лента вопросов, финальный CTA и footer Phase 1 больше не входят в текущую главную. Для самостоятельной демонстрации достаточно типизированных файлов данных.

Этап принимается после функциональной проверки перечисленных сценариев, проверок по [TESTING.md](../development/TESTING.md) и обновления фактического состояния. Создание документации само по себе не завершает MVP.
