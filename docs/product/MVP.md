# MVP Sophia

Область включает главную, интерактивную карту `/learn`, Атлас, доступные уроки и фундамент аккаунтов из Sprint 07. Статус реализации описан в [CURRENT_STATE.md](../development/CURRENT_STATE.md).

| Входит | Критерий готовности |
| --- | --- |
| Главная страница `/` | Ровно три основные секции: Hero, превью курса, выбор направления; необходимая навигация |
| «Вопрос дня» в Hero | Новый вопрос в полночь по Москве, три варианта, объяснение со ссылкой после подтверждения и локальная серия за последовательные дни |
| Превью образовательного маршрута | Показывает пример последовательности обучения без обещания доступного полного курса |
| Выбор направления | Карточка основного курса, средняя карточка разговора с философом и третья карточка «— / Скоро» |
| Разговор с философом | Платон доступен подтверждённому аккаунту с серверным правом `ai_chat`. Другие посетители видят состояние Sophia Premium и ссылки на бесплатные разделы. Память разговора живёт во вкладке |
| Аккаунт | Регистрация, подтверждение email, вход, выход, восстановление пароля и изменение имени в защищённом профиле |
| Учебный прогресс | У гостя зачёты и позиции сохраняются локально. Аккаунт синхронизирует подтверждения слайдов, завершения и места возобновления. Гостевые данные переносятся по явному согласию |
| Атлас | Доступен гостям и зарегистрированным пользователям |
| Страница `/learn` | Название курса, возврат на `/` и горизонтальная карта пяти эпох: в Античности четыре основных узла и ветка Платона, в остальных эпохах по пять шагов; каталог Платона содержит три раздела-каркаса; логотип и компактная ссылка «Как это работает» сохранены |
| Пейзаж карты | Масштаб выбранного прототипа: мир 5900 × 650 px, детальные рисованные области шириной 1180 px, одна эпоха на видимую область карты и естественные переходы; встроенная тропа и объёмные кнопки под материалы эпох; без видимых прямоугольных стыков и крупных заголовков внутри пейзажа |
| Навигация карты | Компактный выбор эпох, перетаскивание, прокрутка, сенсорные жесты и клавиатура; reduced motion и отсутствие горизонтального переполнения страницы |
| Ознакомление с темой | Нажатие шага открывает доступный диалог с темой и явным сообщением о том, что полный урок пока недоступен; закрытие возвращает фокус |
| Адаптивный интерфейс | Основные сценарии работают на мобильных и настольных экранах с клавиатуры |

CTA курса ведут на `/learn`, логотип ведёт на `/`, а ссылка «Как это работает» — на `/#how-it-works`. Шапка даёт доступ ко входу или профилю в зависимости от сессии.

За пределами Sprint 07 остаются платежи, подписки, покупка Premium, читалка, вопрос дня, XP, социальные функции, долговременная память чата и новые AI-собеседники.

Этап принимается после функциональной проверки перечисленных сценариев, проверок по [TESTING.md](../development/TESTING.md) и обновления фактического состояния. Создание документации само по себе не завершает MVP.
