# Библиотека и читалка Sophia

Проверено 26 ноября 2026 года.

## Возможности

Третья карточка главной и пункт меню ведут на `/library`. Каталог ищет по названию и автору, фильтрует «Все», «Читаю» и «Прочитано», показывает прогресс и поднимает начатые произведения по времени последней активности.

Читалка открывает текст, оглавление и переходы между разделами без перезагрузки. Доступны три темы, шрифт 14–28 px, межстрочный интервал 1,2–2,2 и сведения об издании. Можно поставить несколько закладок, переходить к ним и удалять их. Ручную отметку «Прочитано» можно снять. Чтение доступно гостям и отдельно от учебной статистики, календаря и серии ежедневных вопросов.

## Издание и право публикации

Автор всех шести произведений — Платон, переводчик — Василий Николаевич Карпов (1798–1867). Взяты части I–IV второго исправленного и дополненного издания «Сочинений Платона», напечатанные в 1863 году типографией духовного журнала «Странник» в Санкт-Петербурге. Запись РГБ подтверждает состав и год каждой из четырёх частей. [Каталог издания РГБ](https://search.rsl.ru/ru/record/01003507492) · [Сведения о переводчике](https://search.rsl.ru/ru/record/01002507635)

Все шесть переводов опубликованы при жизни Карпова. По ст. 1281–1282 части четвёртой ГК РФ исключительное право истекло. Каждый перевод можно повторно публиковать в России как общественное достояние с сохранением авторства, имени и неприкосновенности произведения. В читалке указаны автор, переводчик и издание. Использованы полные тексты исторических переводов в орфографии транскрипций Викитеки. Вступительные статьи, комментарии, списки действующих лиц и издательские сноски доступны у источника. ## Архитектура и данные

`corpus/catalog.json` хранит выходные данные, структуру, объёмы разделов и карту указателей Стефана. Библиотека получает поля карточек. Читалка получает метаданные выбранного произведения, определяет нужный раздел и делает один запрос к `GET /api/reader/[workId]/[sectionId]`. Сервер сверяет пару ID с каталогом, читает один локальный JSON и возвращает публичный текст. React выводит текст обычными текстовыми узлами. Внешний источник открывается по нажатию ссылки в сведениях об издании.

В `corpus/<workId>/<sectionId>.json` каждый абзац имеет стабильный уникальный ID. Разметка поддерживает явную метку Стефана, продолжение абзаца и имя говорящего. Новое произведение добавляется записью каталога, разделами и локальной обложкой. Для ссылок из уроков предусмотрена функция `readerHref(workId, reference)`. Открытие такой ссылки оставляет записанную позицию до начала прокрутки или явного перехода по оглавлению.

Гостевой снимок использует `sophia.reader.v1`, аккаунт — `sophia.account.<id>.reader.v1`. Позиция включает ID раздела и абзаца и долю внутри него. При изменении размера окна, шрифта или интервала читалка возвращает этот фрагмент к строке чтения. Процент считается по числу символов с начала всего произведения. Последняя позиция, максимальный процент, время активности и ручное завершение сохраняются раздельно. Закладка хранит произведение, раздел, абзац, отрывок, дату и метку при наличии. При удалении аккаунта существующий механизм очищает весь его локальный префикс. При недоступном хранилище или ошибке определения сессии читалка работает с временными данными вкладки.

## Размер и production-сборка

- Каталог и 34 JSON раздела занимают **2 119 229 байт**. Семь WebP занимают **284 418 байт**, включая иллюстрацию главной. Общий объём — **2 403 647 байт**.
- Добавлены три динамических маршрута. Production-трассировка API включает все 35 JSON. При ручной упаковке для `next start` в релиз следует включить `src/features/reader/corpus/` в исходной структуре.
- Прямой переход на `/reader/republic#514a` делает один запрос книги VII объёмом **121 098 байт** до HTTP-сжатия. Самый крупный раздел весит **147 448 байт**. Проверочный фрагмент книги VII отсутствует в клиентских JS-чанках.
- Новых runtime-зависимостей нет. Измерения выполнены на локальной production-сборке Windows. Нагрузку на целевой Ubuntu/Nginx и чтение на физических устройствах предстоит замерить отдельно.

## Проверки

- `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build` и `git diff --check`.
- Семь тестов корпуса и хранилища. Проверены объёмы, указатели, ID, повреждённые и недоступные данные, окончание чтения по ручной команде, сохранение максимума и обновления между вкладками.
- **44 проверки Playwright прошли**, включая 14 сценариев читалки и 30 регрессий главной, аккаунтов и учебного прогресса. В Chromium desktop и mobile проверены поиск, фильтры, все шесть произведений, три темы, размер шрифта, интервал, восстановление при перезагрузке и смене ориентации, закладки, ручное завершение, три адреса Стефана, оглавление и ленивая загрузка «Государства». Проверены гость, два аккаунта и удаление одного аккаунта. Библиотека и настройки чтения прошли axe WCAG 2 A/AA. Итоговый прогон выполнен на отдельно запущенном локальном `next start` с тестовой SQLite и файловой почтой.
- Серверные проверки аккаунтов и учебного прогресса дали 34 и 8 успешных тестов. Полный набор сайта не запускался.
