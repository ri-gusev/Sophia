# Тематические курсы Sophia

## Маршруты

| Адрес | Страница |
| --- | --- |
| `/courses` | «За пределами курса» с четырьмя направлениями |
| `/courses/political-philosophy` | Политическая философия |
| `/courses/russian-philosophy` | Русская философия |
| `/courses/eastern-philosophy` | Восточная философия |
| `/courses/history-of-philosophy` | История философии |

На странице направления есть обложка, описание, ссылка на каталог и область уроков со статусом «Курс находится в разработке». Неизвестный адрес направления возвращает HTTP 404.

## Навигация

Общая шапка показывает список образовательных разделов по нажатию кнопки «Обучение». На узком экране кнопка находится внутри существующего мобильного меню. Список доступен через Tab и Shift+Tab, закрывается при выборе направления, потере фокуса, нажатии вне группы или по Escape. Escape возвращает фокус к кнопке группы. Раскрытие на десктопе происходит поверх страницы. Настройка reduced motion отключает переходы. Атлас, основной курс и читалка используют свои специализированные оболочки.

## Модель и расширение

Данные находятся в `src/features/thematic-courses/catalog.ts`. Добавление направления требует записи с уникальным стабильным `slug` и локальным WebP. Сетка каталога, метаданные и список параметров страницы направления строятся из записей. У курса и каждой ссылки на урок есть независимое поле `access` со значениями `free` и `premium`. Сейчас страницы направлений публичны, а массивы уроков пусты. Право пользователя на чтение в будущем будет определять сервер при выдаче урока. Например, в платном направлении можно будет выделить бесплатное введение с собственным уровнем доступа.

После публикации реальных уроков `lessonId` можно будет связать с движком уроков, существующим учётом прогресса и отображением в профиле. Для первоисточников эти уроки смогут использовать идентификаторы действующего корпуса. [Архитектурное решение](../architecture/DECISIONS.md#adr-028--тематические-курсы-как-каталог-направлений-2026-11-27).

## Обложки

Четыре изображения размером 1440 × 810 px занимают 653 818 байт на диске. Каталог и страницы направлений используют одни и те же файлы. `next/image` выбирает адаптивные варианты. [Происхождение, условия использования, запросы и размеры файлов](../../public/images/courses/README.md).

В новых контекстах Chromium измерен объём ответов с обложками на локальном production-сервере. Для каталога измерение включает все четыре изображения после прокрутки. Для страницы направления измерена обложка политической философии.

| Страница | Настольный экран 1440 px, DPR 1 | Мобильный экран 390 px, DPR 3 |
| --- | ---: | ---: |
| Каталог | 124 106 байт, варианты 640 px | 286 176 байт, варианты 1080 px |
| Политическая философия | 59 504 байта, вариант 750 px | 104 610 байт, вариант 1080 px |

Указан размер тел ответов по Resource Timing. Замеры относятся к локальной сборке и этим двум профилям Chromium. [Данные по каждому изображению](../../artifacts/thematic-courses/image-transfer.json).

## Проверки

- Итоговые `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd run build` и `git diff --check` завершились успешно. Сборщик выдал два известных предупреждения о псевдоэлементах `::highlight()` читалки.
- Полный Playwright на production-сборке до последней правки размера заголовка дал 411 успешных сценариев и 7 штатных пропусков. Настольный и мобильный профили использовали разные тестовые базы.
- На итоговой сборке `npm.cmd test -- tests/thematic-courses.spec.ts tests/phase-two.spec.ts tests/atlas.spec.ts` дал 56 успешных сценариев и 6 штатных пропусков. Прошли все 14 сценариев каталога в двух профилях, в том числе загрузка обложек, четыре перехода и возврат, 404, Tab и Escape, индикация текущего раздела, axe и перенос длинного заголовка. Просмотрены шесть итоговых снимков. Все четыре заголовка проверены на восьми ширинах от 320 до 1440 px на итоговой сборке.
- В Node.js прошли проверки аккаунтов (34), прогресса (8), чата (58), корпуса (4), читалки (14) и интеграции чата (7).

Мобильные браузерные проверки выполнены в эмуляции Chromium. После завершения сценариев на Windows тестовые процессы Next.js были остановлены вручную, чтобы Playwright записал отчёты и вышел.
