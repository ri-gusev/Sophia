## Размещение новых модулей

Следовать уже принятому корню `src/`:

- Размещать маршруты в `src/app/` по соглашениям App Router.
- В маршрутах оставлять композицию страниц и границы фреймворка; предметную логику держать рядом с соответствующей функциональностью вне файлов маршрутов.
- Общие UI-примитивы размещать в `src/components/ui/`; специализированные компоненты держать рядом с функцией, которой они принадлежат.
- Типизированный учебный контент размещать отдельно от TSX, например в `src/content/`.
- Общие утилиты выделять только при реальном повторном использовании; не превращать `lib/` в склад несвязанных функций.
- Статические публичные ресурсы размещать в `public/`, когда они понадобятся.
- Серверный доступ к данным выделять только при утверждённой задаче на хранение; не импортировать его в клиентские компоненты.

Не создавать пустые каталоги, сервисы и компоненты ради схемы. Обновлять таблицу при появлении новых фактических модулей.
