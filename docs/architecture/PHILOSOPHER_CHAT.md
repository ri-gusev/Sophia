# Чат Платона и память вкладки

## Поток

Общее окно на `/` и `/learn` использует `PlatoChatProvider` в корневом layout. Память находится только в React state: закрытие окна и клиентский переход между страницами её сохраняют, reload или закрытие вкладки очищают. Нет cookies, localStorage/sessionStorage, таблиц переписки или серверных сессий.

```text
Окно → POST /api/philosopher-chat → валидация/ограничитель
  → read-only поиск источников → сжатие старых пар при необходимости
  → OpenAI Responses → ответ + ограниченная память → React state
```

Маршрут `src/app/api/philosopher-chat/route.ts` использует Node.js runtime. В `src/features/philosopher-conversation/server/` разделены HTTP, прикладная логика, источники и OpenAI. Общий `chat-contract.ts` не содержит ключа или доступа к БД. Сервер принимает только `philosopherId=plato`. Другие собеседники пока недоступны. Зависимости и отдельные службы не добавлены.

## Память и стоимость

| Часть | Лимит |
| --- | --- |
| Вопрос | 2000 символов |
| Ответ в памяти | 6000 символов; генерация до 900 output tokens |
| Недавняя история запроса | 12 сообщений / 16000 символов, полные пары user/assistant |
| Резюме | 2000 символов; генерация до 450 output tokens |
| Выдержки | До четырёх по 1200 символов |
| Отображаемая история | 40 сообщений / 96000 символов |
| HTTP JSON | 96 KiB |

Перед превышением окна старые пары сворачиваются в резюме. Остаются до двух последних пар; для длинных реплик может остаться меньше. Все удаляемые пары включаются в сжатие. Новая память применяется только после успешного ответа; ошибка сохраняет прежнюю память и восстанавливает вопрос. Источники не накапливаются в памяти.

Короткий ход требует одного API-запроса. При достижении лимита добавляется один короткий запрос сжатия. Резюме является сжатием с потерями. Экономия достигается ограничением контекста каждого вызова; символы ограничивают размер, но не являются точным подсчётом токенов. Недоступность корпуса проверяется до любого платного вызова.

## Источники и роль

Единая SQLite-база открывается только для чтения. Выбираются последние версии документов, связанных с `plato`, проверяется SHA-256. База и исходники не изменяются. Unit-тесты используют синтетические документы. Реальный корпус не просматривался вручную; при проверке выводились только метаданные совпадений.

Поиск лексический: нормализованные слова и основы в перекрывающихся окнах. Это не семантический поиск. Лимиты: до 32 документов, каждый до 2 MiB, суммарно до 4 MiB. Превышение или повреждение даёт контролируемую ошибку. Без совпадений модель должна обозначать нехватку подтверждения, не приписывать общие рассуждения Платону как документированный факт.

Постоянные инструкции задают учебный образ Платона, понятный русский язык и помощь в рассуждении, запрещают вымышленные цитаты и выдачу себя за историческую личность. История, резюме и выдержки — недоверенные данные. UI выводит обычный текст через React, без исполнения HTML. Материалы показываются при ссылках модели `[1]` и т.д.

## Сервер и ключ

Нужен **Node.js >=24.0.0** для `node:sqlite`. В `.env.local`:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5.4-mini
```

Модель по умолчанию — `gpt-5.4-mini`, reasoning `none`. Другие семейства требуют проверки совместимости параметров. URL OpenAI фиксирован; клиент не выбирает URL, модель, ключ или роль system/developer. Ключ только в Authorization серверного запроса, `.env.local` игнорируется Git.

Используется `store:false`, без Conversations API и previous_response_id. Это не обещание отсутствия журналов у OpenAI: действуют [политики хранения провайдера](https://developers.openai.com/api/docs/guides/your-data). Sophia не пишет переписку и сырые ошибки провайдера в свои журналы или БД. Ответы маршрута имеют `Cache-Control: no-store`.

Проверяются Origin и фактический Host, без доверия forwarded-host. Ограничитель одного процесса: до 20 запросов в минуту и два одновременно, без очереди. Это не распределённая защита или денежный бюджет OpenAI. Авторизация пока отсутствует; публичное развёртывание потребует отдельного решения для доступа и расходов. Обычный запуск привязан к loopback.

Провайдер ограничен 25 секундами на вызов, серверный ход — 45, клиент — 50. Отмена сразу освобождает UI, прерывает запрос и игнорирует поздний ответ. Она не гарантирует отмены уже начисленных расходов. Ошибки возвращаются без ключей, текста корпуса и сырого тела API.

При переносе сервера корпус должен находиться в закрытом постоянном `storage/knowledge/`, отдельно от клиентских ресурсов; [бэкап](KNOWLEDGE_STORAGE.md). Эфемерная serverless-файловая система пока не поддержана как схема хранения.

Проверки: `test:chat`, `test:knowledge`, TypeScript, ESLint, build и Playwright. Решение — ADR-012 в [DECISIONS.md](DECISIONS.md). Ссылки: [Responses и инструкции](https://developers.openai.com/api/docs/guides/text), [модель GPT-5.4 Mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini).
